## Возможности

### Telegram-бот
- **Добавление трат естественным языком:** «кофе 350», «такси 1200 вчера»
- **Просмотр статистики:** «сколько потратил на еду в этом месяце», «покажи траты за неделю»
- **Изменение:** «последнее было не 350, а 450»
- **Удаление:** «удали такси»
- **Изоляция данных:** каждый член семьи видит только свои траты

### Веб-панель
- Список всех трат семьи с фильтрацией по пользователю, категории, периоду
- Создание, редактирование, удаление трат
- Без авторизации (по ТЗ)

### Ключевые архитектурные решения

1. **Модульная монолитная архитектура.** Микросервисы избыточны для семейного проекта. Чистая архитектура даёт тестируемость и возможность замены компонентов без переписывания бизнес-логики.

2. **Интеграция LLM через structured output.** Бот не хранит «сырой» текст — он сразу парсит его в структурированное действие через LLM с JSON-schema. Это даёт предсказуемость: бот всегда знает, что делать, и не пытается «угадать» намерение.

3. **Изоляция данных по user_id.** Все запросы к репозиторию неявно фильтруются по `user_id` (кроме веб-панели главы семьи, которая имеет доступ ко всем записям).

4. **Конфигурируемый LLM-провайдер.** Интерфейс `LLMClient` с реализациями для OpenAI и других провайдеров. Выбор через конфиг.

5. **Веб-панель без авторизации.** По ТЗ — без авторизации. Веб-панель работает со всеми тратами семьи.

## Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone <repo-url>
cd family-expenses
```

### 2. Настройте конфигурацию

Отредактируйте `configs/config.yaml` и/или `deployments/.env`:

**configs/config.yaml:**
```yaml
server:
  host: "0.0.0.0"
  port: 8080

database:
  url: "postgres://app:secret@localhost:5432/expenses?sslmode=disable"

telegram:
  token: ""                           # ← Оставьте пустым если бот не нужен
  poll_timeout: 60
  proxy_url: ""                       # ← прокси (http/socks5), если api.telegram.org заблокирован

llm:
  provider: "ollama"                  # или "openai"
  base_url: "http://localhost:11434/v1"
  api_key: "ollama"                   # для Ollama любое значение
  model: "deepseek-r1:8b"
  temperature: 0.1
  max_tokens: 1024
  timeout: 120s                       # таймаут (для локальных LLM >60s)

web:
  port: 3000
```

**deployments/.env:**
```
TELEGRAM_TOKEN=                         # пусто — бот отключён
TELEGRAM_PROXY=                         # прокси (https/http/socks5), если api.telegram.org заблокирован
OPENAI_API_KEY=ollama                   # или ваш ключ OpenAI
LLM_BASE_URL=http://host.docker.internal:11434/v1
LLM_TIMEOUT=120s                        # таймаут LLM (для локальных моделей ставьте >60s)
```

> **Важно:** Telegram-бот опционален. Если `TELEGRAM_TOKEN` пустой, бот просто не создаётся — API и веб-панель работают без него.

### 3. Запуск через Docker Compose (рекомендуется)

```bash
make up
```

Сервисы будут доступны:
- **Веб-панель:** http://localhost:3000
- **REST API:** http://localhost:8080
- **Health check:** http://localhost:8080/health
- **PostgreSQL:** localhost:5432

### 4. Локальный запуск (без Docker)

```bash
# Установка зависимостей
go mod tidy

# Запуск PostgreSQL (локально или через Docker)
docker run -d --name expenses-db \
  -e POSTGRES_DB=expenses \
  -e POSTGRES_USER=app \
  -e POSTGRES_PASSWORD=secret \
  -p 5432:5432 postgres:16-alpine

# Только API + веб-панель
make run-api

# Только Telegram-бот
make run-bot

# API + бот одновременно
make run-all
```

Бинарник запускается с флагом `-service`, который определяет режим:
```bash
go run . -service api       # только HTTP API + веб-панель
go run . -service bot       # только Telegram-бот
go run . -service all       # оба сервиса одновременно
```

## Конфигурация

Все параметры задаются в `configs/config.yaml` или через переменные окружения (переменные имеют приоритет).

| Переменная | Описание | Пример |
|---|---|---|
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgres://app:secret@localhost:5432/expenses` |
| `TELEGRAM_TOKEN` | Токен Telegram-бота (пусто = бот отключён) | `123456:ABC-DEF...` |
| `TELEGRAM_PROXY` | Прокси для Telegram API (HTTP/SOCKS5) | `http://host.docker.internal:8080` |
| `OPENAI_API_KEY` | Ключ LLM-провайдера | `sk-...` или `ollama` |
| `LLM_BASE_URL` | Базовый URL LLM API (для локальных моделей) | `http://localhost:11434/v1` |
| `LLM_TIMEOUT` | Таймаут запроса к LLM (default: 120s) | `120s`, `60s`, `180s` |

### Конфигурация LLM

```yaml
llm:
  provider: "openai"                    # openai, ollama, или любой совместимый
  base_url: "https://api.openai.com/v1" # или локальный сервер
  api_key: "sk-..."
  model: "gpt-4o-mini"                  # или любая другая модель
  temperature: 0.1                      # низкая температура для предсказуемости
  max_tokens: 1024
  timeout: 30s                          # таймаут запроса к LLM
```

**Для локальных моделей (Ollama):**
```yaml
llm:
  provider: "ollama"
  base_url: "http://localhost:11434/v1"
  api_key: "ollama"                     # для Ollama любое значение
  model: "deepseek-r1:8b"               # или llama3.1, qwen и др.
  timeout: 120s                         # локальные модели думают дольше
```

## Модель данных

### Сущность «Трата» (Expense)

| Поле | Тип | Описание |
|---|---|---|
| `id` | UUID | Идентификатор траты |
| `user_id` | BIGINT | Telegram ID владельца |
| `amount` | DECIMAL(10,2) | Сумма (должна быть > 0) |
| `category` | VARCHAR(32) | Категория траты |
| `spent_at` | TIMESTAMP | Дата траты |
| `comment` | TEXT | Необязательный комментарий |
| `created_at` | TIMESTAMP | Время создания записи |
| `updated_at` | TIMESTAMP | Время последнего изменения |

### Категории

| Значение | Описание |
|---|---|
| `еда` | Кафе, рестораны, продукты |
| `транспорт` | Такси, метро, автобус |
| `жильё` | Аренда, коммуналка |
| `развлечения` | Кино, игры, хобби |
| `здоровье` | Аптека, врач |
| `покупки` | Одежда, техника |
| `алкоголь` | Напитки, бар |
| `другое` | Не попало в категории выше |

### Индексы

```sql
CREATE INDEX idx_expenses_user_spent ON expenses(user_id, spent_at DESC);
CREATE INDEX idx_expenses_category ON expenses(category);
```

```
GET /api/expenses
```


## Интеграция с LLM

### Принцип работы

1. Пользователь отправляет сообщение боту: «кофе 350»
2. Формируется промпт с системной инструкцией и текущей датой
3. LLM возвращает структурированный JSON с действием и параметрами
4. Сервис валидирует и выполняет действие
5. Пользователь получает подтверждение

### Системный промпт

Бот использует строго структурированный системный промпт, который инструктирует LLM возвращать только валидный JSON без пояснений. Возможные действия:

- **`add`** — добавить трату (сумма, категория, дата, комментарий)
- **`list`** — показать траты или статистику (фильтр по категории, периоду)
- **`update`** — изменить последнюю трату (новая сумма)
- **`delete`** — удалить трату

### Примеры взаимодействия

**Добавление:**
```
Пользователь: кофе 350
Бот: ✅ Записал: кофе, 350 ₽ (еда), 16.10.2026
```

**Добавление с датой:**
```
Пользователь: такси 1200 вчера
Бот: ✅ Записал: 1200 ₽ (транспорт), 15.10.2026
```

**Просмотр:**
```
Пользователь: сколько потратил на еду в этом месяце
Бот: 💰 кофе: 350 ₽ (еда), 16.10.2026
     💰 обед: 800 ₽ (еда), 15.10.2026
     📊 Итого: 1150 ₽ за 2 записей
```

**Изменение:**
```
Пользователь: последнее было не 350, а 450
Бот: ✏️ Обновил: кофе, 450 ₽ (еда), 16.10.2026
```

**Удаление:**
```
Пользователь: удали такси
Бот: 🗑 Удалил: 1200 ₽ (транспорт), 15.10.2026
```
